# apphouse.ai

ai-powered app factory. describe your app, 9 agents build it.

## stack

- **monorepo**: turborepo
- **web**: next.js 14+ (app router)
- **mobile**: expo / react native (ios + android)
- **backend**: supabase (multi-tenant, single project)
- **hosting**: vercel
- **domains**: godaddy
- **ai**: claude api (anthropic)
- **payments**: stripe
- **analytics**: posthog + sentry

## the 9 agents

```
ux → wireframes → ui → dev → data → ai → sales → cfo → pm
```

each agent is a specialized claude instance that must reach 100% understanding before proceeding.

## structure

```
apphouse.ai/
├── apps/
│   ├── landing/               # apphouse.ai portal
│   ├── _template/             # web app template (next.js)
│   ├── _template-mobile/      # mobile app template (expo)
│   └── [your-apps]/           # generated by pipeline
├── packages/
│   ├── agents/                # 9 agent configs + orchestrator
│   ├── ui/                    # shared components + design tokens
│   ├── supabase-client/       # multi-tenant supabase client
│   └── utils/                 # shared utilities
├── supabase/migrations/       # database schema
├── scripts/                   # create-app, setup-keys
├── turbo.json
└── package.json
```

## quick start

```bash
# install
npm install

# run portal
npx turbo dev --filter=landing

# create a new app
./scripts/create-app.sh my-app "my app" "myapp.com"
./scripts/create-app.sh my-app "my app" "myapp.com" full  # web + mobile
```

## setup

```bash
# 1. clone and install
git clone https://github.com/YOUR_ORG/apphouse.ai.git
cd apphouse.ai
npm install

# 2. configure api keys (interactive)
chmod +x scripts/setup-keys.sh
./scripts/setup-keys.sh

# 3. set up supabase
npx supabase init
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase db push

# 4. deploy portal
cd apps/landing
npx vercel link
npx vercel --prod
npx vercel domains add apphouse.ai
```
